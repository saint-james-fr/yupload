PLEASE READ BEFORE INSTALL

1.Install the application based on your operating system: Windows, macOS.

2.Run the application.

** IMPORTANT FOR macOS USERS **
If you see a security warning like "Apple cannot check that 'Yupload.app' is free from malware", follow these methods:

a. Open Terminal
c. Copy: sudo xattr -rd com.apple.quarantine
d. Drop the app from applications in the terminal, it will copy the path. Press Enter.
d. Enter your password when prompted: it's normal nothing appears, it's still typing. Press Enter to validate.
e. Double-click Yupload.app to open normally


This warning appears because the app is not code-signed with an Apple Developer certificate - whichs costs 99$/year.

3.Connect YouTube for video uploads (Settings → General - Accounts).
a. First, be sure to select continue (google oauth-1.png)
b. When asked, select both scopes (see google oauth-2.png)

4.Connect Discogs for metadata auto-fill (Settings → General - Accounts).

5.You're ready to create videos from audio files and images.
