PLEASE READ BEFORE INSTALL

1.Install the application based on your operating system: Windows, macOS.

2.Run the application.

3.Connect YouTube for video uploads (Settings → General - Accounts).
a. First, be sure to select continue (google oauth-1.png)
b. When asked, select both scopes (see google oauth-2.png)

4.Connect Discogs for metadata auto-fill (Settings → General - Accounts).

5.You're ready to create videos from audio files and images.
